# TKS Pilates

Site do TKS Pilates (Penha e Vila Guilhermina, São Paulo). Página única e estática, publicada pelo GitHub Pages.

- `index.html`: a página inteira (HTML, CSS e JS juntos). A primeira tela é um Reformer desenhado em código, com uma aluna fazendo footwork, alças e prances.
- `img/`: fotos reais dos estúdios e da equipe, e o logo.

Os botões de WhatsApp abrem o (11) 99217-1881 com a mensagem pronta para agendar a aula avaliação gratuita.
